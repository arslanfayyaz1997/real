# Add a realistic animated human (GLB)

The project is prepared for a rigged GLB character. The bundled placeholder is procedural, so to get a more realistic human, download a rigged character that includes a walk animation and add it as:

`public/realistic-walker.glb`

## Free CC0 animated human option

Innerscene's **Relaxed walk — Sam 3D Person, Animated** is a textured, rigged adult human with a looping walk animation and CC0 license (free to use commercially):

https://www.innerscene.com/tools/library/3d-parts/relaxed-walk-sam-3d-person-animated-732f1206

Open the page and choose **Download GLB**, then save it as `realistic-walker.glb` inside `public/`.

Important: this is a textured 3D person with casual clothes, not a photorealistic film actor, and it does not include a laptop bag. For the exact formal outfit + laptop bag brief, use a compatible rigged GLB model that includes those details or add a separate bag prop in Blender. Keep the asset's own licence with the project.
